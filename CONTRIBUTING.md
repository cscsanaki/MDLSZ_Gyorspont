# Közreműködés

Köszönöm, hogy szeretnél hozzájárulni az MDLSZ Gyorspont fejlesztéséhez!

## Hibajelentés és ötletek

Hibát vagy fejlesztési javaslatot a GitHub Issues oldalon jelezhetsz. Írd le röviden, mit tapasztaltál, és hogyan lehet előidézni a hibát. Ha lehet, add meg a program és a Windows verzióját is. Képernyőkép csatolásakor ügyelj arra, hogy ne látszódjanak személyes vagy versenyzői adatok.

## Kódmódosítások

Nagyobb módosítás előtt nyiss egy Issue-t, és írd le, mit szeretnél változtatni.

Pull request küldéséhez:

1. Forkold a repositoryt, és hozz létre egy külön branchet a módosításaidnak.
2. Tartsd a változtatásokat a lehető legáttekinthetőbbnek, és kövesd a meglévő Python-kód stílusát.
3. Futtasd az alkalmazást Windows alatt, és ellenőrizd az érintett funkciókat.
4. Ha a módosítás a program csomagolását is érinti, futtasd a `build_exe.bat` fájlt, majd próbáld ki a létrejött `dist/MDLSZ_Gyorspont.exe` fájlt.
5. Küldj pull requestet a `main` branch felé. A leírásban foglald össze a változtatást és azt, hogyan ellenőrizted.

Ne tölts fel valódi versenyzői adatokat, jelszavakat vagy hozzáférési tokeneket!
