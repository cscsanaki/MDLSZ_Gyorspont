# Biztonsági szabályzat

## Támogatott verziók

Biztonsági hibák javítása a legfrissebb kiadáshoz készül.

| Verzió | Támogatott |
| --- | --- |
| Legfrissebb kiadás (jelenleg v1.0.2) | Igen |
| Korábbi kiadások | Nem |

## Sérülékenység bejelentése

Feltételezett biztonsági hibát kérjük, ne jelents nyilvános GitHub Issue-ban. Küldd el e-mailben a **cscsanaki@gmail.com** címre.

A bejelentésben add meg az érintett programverziót, a hiba leírását, az előidézés lépéseit és a lehetséges hatást. Kérjük, ne küldj valódi versenyzői vagy más személyes adatokat.

Amint tudok, visszajelzek a bejelentésről.
